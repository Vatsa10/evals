Is Evals built on DeepEval?

Evals has its own runner, graders, tracing, and storage. We studied DeepEval, Langfuse, LangSmith, and Anthropic’s evaluation guidance for ideas. There is no DeepEval runtime dependency.

Do I need a hosted account?

No. The engine runs locally with Python 3.11+ and no third-party runtime dependencies. Your application or custom LLM judges use their own model credentials. The coding-agent route uses your existing Claude Code or Codex setup.

Can I evaluate my existing application?

Yes. Connect it with a Python function or a command that reads and writes JSON. Your adapter returns the available evidence: responses, tool calls, retrieved documents, messages, or environment state. The plugin can write this integration for you.

Can I bring my own graders and models?

Yes. Built-in checks cover exact values, patterns, JSON, numeric limits, tools, and labeled retrieval. Custom adapters support domain checks and LLM judges with your provider, rubric, scores, and evidence.

What does monitoring include today?

Continuous suite runs, request tracing, conversation IDs, online grading policies, SQLite history, local alerts, and a loopback JSON API. Hosted dashboards, external alert delivery, and provider auto-instrumentation are future extensions.
